# ALPHA — Autonomous Fire Extinguishing Rover

## About
Autonomous rover-fire extinguishing system designed to detect 
and suppress fires in hazardous environments, minimizing human risk.

Originally conceived in 2019 as a gesture-controlled robot. Evolved into a 
fully autonomous system as a final-year project (2025).

🏆 **IEEE YESIST12 JR Einstein Competition — Finalist (Stanford University, Thailand, 2019)**

## Features
- LIDAR, ultrasonic, radar, flame, smoke & temperature sensor fusion
- Autonomous navigation & obstacle avoidance
- Indoor mapping & outdoor geo-fencing
- CO₂ suppression system with real-time alerts
- Autonomous return-with-feedback capability
